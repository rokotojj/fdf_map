# fdf_map

# FdF - каркасная 3D-модель карты высот

![скриншот](screenshot.png)

## Описание

Каждая точка карты соединяется с соседом справа и снизу, так что каждое ребро рисуется
один раз. Проекция:

```
x' = (x - y) * cos30
y' = (x + y) * sin30 - z * z_scale
X = x' * scale + offset_x,  Y = y' * scale + offset_y
```

При открытии и при изменении размера окна карта масштабируется так, чтобы занимать 90 %
окна, и ставится по центру. Модель можно вращать и наклонять мышью и приближать колесом.

Путь к карте задаётся в начале `lab1.py`:

```python
MAP_PATH = "swap.fdf"
```

## Управление

| Клавиша / действие | Что происходит |
|---|---|
| Левая кнопка мыши + движение влево-вправо | поворот модели вокруг вертикальной оси |
| Левая кнопка мыши + движение вверх-вниз | наклон: вверх - вид сверху, вниз - вид сбоку |
| Колесо мыши | масштаб |
| Esc или закрытие окна | выход |

Линии создаются один раз при открытии карты, при повороте и масштабе у них меняются только координаты.
